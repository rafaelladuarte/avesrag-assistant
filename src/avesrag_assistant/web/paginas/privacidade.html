Privacidade

Este é um beta fechado, feito para testar o assistente. Veja o que acontece com o que você escreve.

O que fica guardado

  • O texto da conversa (suas mensagens e as respostas do assistente) e a ave que você confirmou.
  • O nome do seu convite, para saber de qual teste veio a conversa, e se você marcou “Ajudou” ou “Não ajudou”.
  • Quantas chamadas a conversa gerou, para controlar o custo.

Por quanto tempo

A conversa é apagada automaticamente 14 dias depois da última mensagem.

O que não fica guardado

O seu endereço de rede (IP) não é gravado junto da conversa: ele só existe na memória do servidor, por um minuto, para limitar o uso. Não há cadastro, e-mail nem rastreadores.

Para quem o texto vai

Para entender sua descrição, o texto das mensagens é enviado à OpenAI, que o processa para gerar a resposta e para verificar se o conteúdo é apropriado. Por isso, não escreva dados pessoais (nomes, endereços, telefones): para identificar a ave, basta descrevê-la e dizer o tipo de lugar.

Apagar uma conversa

Para apagar uma conversa antes do prazo, peça a quem organiza os testes, informando o horário aproximado.
